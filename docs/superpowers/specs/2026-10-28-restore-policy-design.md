# 原版备份恢复策略映射

按用户已授权的 1:1 迁移和独立 iOS 调试继续，规范来自源 Restore.kt、BackupConfig.kt 和相关 DAO，不另选产品方案。

恢复须按原表标识 upsert，保留本机独有记录；高亮规则与键盘辅助列表按原版整表替换。缺失类别不修改本机类别，空普通列表不清空。配置按字段应用；读取/解密/合并验证在任何写入之前完成，写入失败保留既有回滚。书籍匹配 bookUrl 时保留目标稳定 id 并重映射导入标注引用，避免目标架构的引用断裂。

新增原版十项恢复忽略：阅读界面、主题模式、主题配色、封面样式、书架布局、显示订阅、线程数、本地书籍、Cookie、书源变量。默认全部不忽略，选择持久化但不随备份覆盖。默认封面文件路径、备份设备名/自动备份/本地书自动恢复及本地密码按源自动忽略。忽略阅读时不激活 bg 媒体；封面媒体仍恢复。

继续使用现有 React Native/MMKV、ZIP 暂存提交和应用内弹层；不加依赖、不改源或 ios/android。保留旧备份格式与明确的未支持 Android 配置解析、章节位置/文件提供方矩阵缺口。源读取记录带设备 id 的完整恢复不在当前已转换类别内，不用目标近似行为宣称已完成。
