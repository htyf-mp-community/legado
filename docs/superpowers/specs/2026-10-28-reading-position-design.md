# 备份后首次目录与文字续读

源合同为 Book.durChapterIndex/durChapterPos、BookHelp.getDurChapter、ContentProcessor 与 TextChapter.getReadLength/getPageIndexByCharIndex。字符位置是 UTF-16 首行位置，不是百分比；当前目标错误地把它写入 progress，且把章节归零。

保持用户的完整 1:1 目标，按现有架构先贯通章节水合和普通文字的分页/滚动位置。转换时保留待加载目录的原章节索引、标题、总数和字符位置；首次访问完整目录用已有原版章节迁移算法定位，不靠占位章节数组推断索引。目录水合后以真实 chapterId 关联字符位置；数据与媒体备份自动携带。

文字位置使用原版“标题＋换行＋缩进非空段落”UTF-16 空间。分页器返回真实切片范围，不能用 pageIndex*capacity 代替；位置和页/段落文本间按实际范围映射。滚动用 iOS Text 的真实行布局事件与段落布局，保存可见首行；首次加载、重排版、程序滚动不提前覆盖待恢复位置。位置更改需与当前书籍其它字段并发安全合并，未加载正文时不消费。

继续独立 iOS、原生目录和依赖不变、源只读。普通文字的实测不替代富 HTML/图片/漫画/媒体秒数/替换规则改变/复杂原版标题拆分的完整矩阵；保留原始数据并记录未证实范围，不称全量完成。
