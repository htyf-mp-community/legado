# 文件书源选择与导入 / File-source chooser (0.0.57)

原版详情页在“加入书架”和“开始阅读”时展示可下载文件名；当前实现此前只显示编号，ZIP 快速下载时还会因为弹层正在关闭而无法重新显示选书列表。本轮增加文件名发现：URL 路径含有效后缀时使用路径名，否则用带原书源请求头的 HEAD 获取文件名或跳转地址，失败则回退到书名/作者，并按书源 `type` 修正后缀。入口区分加入书架与直接阅读。

下载期间保留同一个弹层并显示加载状态，ZIP 文件准备好后原位切换到条目选择；关闭弹层后完成的下载会释放暂存文件，不自动导入。失败显示错误并允许重试。
