# 在线书籍加入与阅读验证

2026-11-03，在独立 iOS 模拟器的 HTYF 宿主中使用默认书源验证。

- 真实书源搜索到《西游记》，详情加载出 100 章目录。
- 临时隔离包首次加入另一部书，直接进入阅读器并加载第 1 章正文；切换到第 2 章后，从搜索结果再次加入，仍停留在第 2 章。
- 重启隔离宿主并从书架打开该书，仍能恢复第 2 章，阅读画面正常。
- 测试前的隔离包可重现 `Rendered more hooks than during the previous render`；修复后重新运行通过。项目 lint 已启用 Hook 顺序检查。
- 全量回归：312 个套件、1863 项测试通过；TypeScript 和 lint 通过。

首次搜索和完整目录检查使用与项目源代码一致的隔离包。为使模拟器测试工具能获取目录底部的按钮，后续临时包仅把详情页的目录预览从 50 条缩短到 1 条；完整章节仍写入书架，阅读、保存及导航代码与项目一致。隔离包使用独立小程序 ID 和存储，未发布，也未验证物理设备或 Android。
