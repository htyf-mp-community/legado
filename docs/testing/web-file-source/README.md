# 在线文件书源 / Online file sources (0.0.55)

**后续修正（0.0.56）**：下文“导入前保留文件”在 0.0.55 并未正确保护 EPUB/MOBI，因为 iOS 的文件选择器会移动文件。该问题已在后续修复并用模拟器验证；详见 [文件保留验证](../web-file-retention/README.md)。

原版类型 3 书源从详情规则的 `downloadUrls` 取得下载文件，而不是加载章节目录。此前目标总是请求目录，空目录也无法加入书架。现在按最终详情地址解析并去重文件链接，空链接明确报错；详情页可选择链接，下载并导入文件。ZIP 内有多本书时只导入选中的条目。下载沿用书源请求头与 Cookie；POST 保留请求体及二进制响应。导入前保留文件，避免 EPUB/MOBI 引用已清除的临时文件；书名、作者、封面和简介按原版 `LocalBook.mergeBook` 合并。

## 验证

- [定向测试](targeted.log)：4 套件、10 项通过，覆盖相对链接和重复链接、空链接、请求头、HTTP 错误、POST 二进制、ZIP 多文件单选、组件失败重试与普通书源详情。
- 在新增最后一项 POST 测试前运行的[完整回归](tests.log)：228 套件、1,164 项通过。类型检查与改动文件 ESLint 通过；POST 测试随后单独通过。
- 独立 iOS 26.5 模拟器加载本轮调试代码后进入书架，显示原有 10 本书，见[启动截图](ios-launch.png)。这是启动检查，不覆盖文件源交互。
- 本轮文件下载、ZIP 选择与导入的证据为自动化测试，**尚未在 iOS 模拟器或真机执行这些交互**。真实「阅读书屋」是普通文本书源，其先前 iOS 真实站验证见 [1321 真实书源](../real-source-1321/README.md)，不能推断本轮文件书源已通过设备验收。

## 边界

本地导入器支持 TXT、EPUB、MOBI、PRC、AZW 与 ZIP 内这些格式；PDF、UMD、AZW3、RAR、7z 及原版不支持格式的下载后外部打开尚未迁移。文件名探测与 UI 也未完全复刻原版。真实受保护站点、真实 HTYF 宿主及手机尚未验证；远程包仍为旧版本，本地包未发布。仅构建 iOS。
