## 2026-11-03：恢复宿主启动

## 实际复现与修复

在专用 iPhone 17 Pro / iOS 26.5 模拟器中安装本机已构建的红糖云服调试宿主（`com.dagouzhi.app.hongtangyun.ios.pro`）。宿主通过仅监听本机的服务下载原样 0.0.57 包后，启动真实小程序时抛出 `InteractionManager has been removed from react-native core`，见[错误截图](interaction-error.png)。堆栈指向 React Navigation stack 的 Card 转场；当前宿主 React Native 为 0.88.1，原生 getter 已移除该 API。

远程构建中仅对 `@react-navigation/stack` 的 Card 导入使用兼容实现，其 `createInteractionHandle` / `clearInteractionHandle` 行为对应目标原本 React Native 0.86 的空操作 stub；独立模拟器构建和其他模块不改。真实 getter 抛错的[失败测试](interaction-red.log)与[修复测试](interaction-green.log)覆盖远程、独立及非目标模块三种情况。当前宿主 Worklets 为 0.13.1；其 Babel 插件与项目内副本逐字节相同。开发构建原先嵌入 0.13.0，已修正版本元数据，[失败](version-red.log)/[通过](version-green.log)测试覆盖；生产包不注入该版本字段。
